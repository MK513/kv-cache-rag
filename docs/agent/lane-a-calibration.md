## 한계 — 차이가 근소하다

- 두 도메인의 차이는 **domain_assessment × TurboQuant 칸 하나**에서만 나온다. 데이터센터 쪽 두 번째 청크(표시 0.840)는 0.84 바로 아래이고, 온디바이스 쪽 네 번째 청크(표시 0.840)는 0.84 이상이다. 즉 Task 수 차이는 유사도 소수 셋째 자리 이하 차이에 걸려 있다.
- 원인: multilingual-e5-small 은 관련 없는 쌍도 유사도가 0.80~0.87 대에 좁게 몰린다. 절대 임계값 하나로는 칸 사이 구분이 약하다.
- 임베딩 revision·코퍼스 해시가 고정돼 있어 **같은 코퍼스·같은 입력이면 재현된다.** 원문·청킹이 바뀌면 다시 보정한다.
- 그래서 README 의 동적 Fan-out 실증은 이 도메인 비교만이 아니라 **재계획 라운드 트레이스(최초 n개 → 재계획 m개)** 를 함께 제시한다.
- 더 안정적인 대안(검토만 하고 이번에는 적용하지 않음): 절대 τ 대신 칸별 최고 점수에서 δ 이내 청크 수 같은 상대 기준. 계획서 §4-1 규칙 변경과 재보정이 필요하다.

## T 선택

τ = 0.84 에서는 T = 2·3·4 결과가 모두 같다. 값에 민감하지 않으므로 중간값 3 을 쓴다.
